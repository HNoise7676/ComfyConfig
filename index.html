Good to know

  • This is an AI-written work in progress. The code was generated by an AI assistant, so expect rough edges and double-check anything important.
  • Use the Install button in the header (or your browser's Install option) to add the app to your desktop or home screen.
  • Matches are ranked by post count, so common tags rise to the top.
  • Commas and spacing are handled for you — no more tag,tag.
  • Underscores in the database become spaces: commentary_request → commentary request.
  • Unknown tags and duplicates are flagged below the editor. Click a warning to review them.
  • Your draft, library and downloaded tag list all work offline after the first load.
  • Use Tidy to normalise a messy prompt, then Sort by popularity if you like your strongest tags first.
